# tecnosanjuan-web

Páginas públicas del sitio de TecnoSanJuan, el club de robótica de NEUROSTEAM LABS S.A.S. (Tuluá, Valle del Cauca).
Sitio estático publicado con GitHub Pages. Los pagos, la tienda y el área de miembros viven en Wix
(`pagos.tecnosanjuan.club`). Este repositorio solo contiene el sitio; se actualiza desde el repositorio de trabajo privado.
